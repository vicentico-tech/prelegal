# prelegal
A platform for drafting legal agreetment

## Status

🚧 This project is in progress and is expected to be completed in 1 week.

## Getting started

Requires [Docker](https://www.docker.com/) with Compose.

```bash
# Mac
scripts/start-mac.sh
scripts/stop-mac.sh

# Linux
scripts/start-linux.sh
scripts/stop-linux.sh

# Windows
scripts/start-windows.ps1
scripts/stop-windows.ps1
```

The app is available at [http://localhost:8000](http://localhost:8000). The SQLite database is recreated from scratch every time the container starts.
