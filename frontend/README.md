# Mutual NDA Creator

A Next.js prototype (Jira [PL-3](https://josegarciama23.atlassian.net/browse/PL-3)) for filling out and downloading a Mutual Non-Disclosure Agreement.

Fill in party details and agreement terms in the form; the document preview on the right fills in live, sourced from the Standard Terms in `../templates/Mutual-NDA.md`. Use "Download PDF" to print/save the finished document. Everything runs client-side — there's no backend or persistence.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
